## 📌 Overview

**Code-Editor** is an interactive, browser-based live code playground designed for **HTML5**, **CSS3**, and **JavaScript (ES6+)**. It provides live preview rendering, split-pane editing, and instant DOM synchronization.

---

## ✨ Key Features

- ⚡ **Real-Time Live Preview**: Instant iframe preview updating on every keystroke.
- 🎨 **Syntax Styling**: Dark theme layout optimized for clean readability.
- 🔀 **Split Pane Editing**: Independent code panels for HTML, CSS, and JS.
- 🚀 **Zero Dependencies**: Pure vanilla JavaScript implementation.
